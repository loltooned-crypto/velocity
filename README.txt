VELOCITY v0.3 - build steps (no coding needed)

1. Free account at github.com, then create a new empty repository named velocity.
2. Upload every file and folder from this zip (keep the folders, including the hidden .github folder).
3. Open the repository's Actions tab, pick "Build VELOCITY", press "Run workflow".
4. When it finishes, open the run and download the VELOCITY artifact. Inside is a .geode file.
5. Windows: put it in %LOCALAPPDATA%\GeometryDash\geode\mods\
   Android: import it with the Geode launcher.
6. In the game, press Tab (PC) or tap the V button (main menu or pause screen) to open VELOCITY.
   Features with a small cog have extra settings. On PC, Q and E switch start positions in a level.

Music: put mp3/ogg/wav files in the "music" folder inside VELOCITY's save folder (the Geode
mods > VELOCITY page has a button that opens it).

Built for Geometry Dash 2.2081 and Geode 5.11.x. This version has NOT been compiled yet. If the
build fails, copy the red error text from the Actions run and send it to me.
